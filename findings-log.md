# Findings log

One row per step of each audit. "Lens or step" is a lens name (for example `path-handling`), or `check.sh`, `security-review`, `adjudication`, or `variant search`. The counts for a lens come from the adjudicator's table for that lens. "Noise notes" records what the step got wrong or wasted time on, so lenses and prompts can be tuned against real results.

This file in sentinel stays an empty template. `/snt:audit` keeps the filled-in copy for each project at `audit/findings-log.md` in that project, which stays out of git with the rest of `audit/`: a row counts confirmed findings, and some of them may not be fixed yet.
